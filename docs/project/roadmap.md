# Roadmap

The root package starts containers through `mongod`, which needs no MongoDB
driver, and needs only the official driver itself. The remaining work is
planned and tracked in GitHub issues;
[#48](https://github.com/TopherGopher/mongotest/issues/48) lists them in
order.
