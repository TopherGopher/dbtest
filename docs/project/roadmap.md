# Roadmap

The root package starts containers through `mongod`, which imports no
MongoDB driver; the root package itself needs only the official one. The remaining work is
planned and tracked in GitHub issues;
[#48](https://github.com/TopherGopher/mongotest/issues/48) lists them in
order.
